# Featured apps

* [MESA CLI (Cloud Shell)](cli.md) - The MESA CLI app, listed as MESA Cloud Shell — a browser terminal on CyVerse VICE with five AI coding-agent CLIs, the MESA MCP servers, CyVerse Data Store tools, and a geospatial conda environment.
* [MESA JupyterLab](jupyterlab.md) - The MESA JupyterLab app — a Python, R, and Julia data-science workbench on CyVerse VICE with RStudio, Shiny, VS Code, AI coding agents, and the MESA MCP servers.
* [MESA RStudio Geospatial](rstudio.md) - The MESA RStudio Geospatial app — RStudio Server on the Rocker geospatial stack (sf, terra, stars, GDAL) on CyVerse VICE, with AI coding agents and the MESA MCP servers.
* [MESA VS Code](vscode.md) - The MESA VS Code app — VS Code in the browser (code-server) on CyVerse VICE with Python, Jupyter, and Cline extensions, AI coding agents, and the MESA MCP servers.
* [MESA KASM Ubuntu Desktop](kasm.md) - The MESA KASM Ubuntu Desktop app — a full Ubuntu 24.04 XFCE desktop in the browser on CyVerse VICE, with web browsers, VS Code, AI coding agents, and the MESA MCP servers.
* [AI agents in the MESA apps](agents.md) - Use the AI coding agents and MESA MCP servers built into every MESA featured app — sign in to CyVerse, connect AI Verde or local Ollama models, and reach your Data Store.
