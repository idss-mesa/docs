# CLAUDE.md — MESA documentation

MESA umbrella repo: the `install.sh` one-liner plus the documentation site
(built with [Zensical](https://zensical.org), deployed to GitHub Pages at
<https://idss-mesa.github.io/docs/>).

Follow the repository agent guide in [AGENTS.md](AGENTS.md) — it covers the
OKF v0.2 bundle structure, the required frontmatter (never add `verified:`),
the documented `docs/index.md` deviation, the validation and generator
commands, and the change-log rules. `site/` is build output — never edit it
by hand.
